# HTML 阅读器契约

## 产物

`finalize` 默认生成单文件 `视频笔记.html`，可脱离同目录其他文件打开；正文和原文均已内嵌。它是本次视频笔记的静态快照，不宣称实时行情或动态更新。脚本在 `scripts/html_reader.py`，无需网络或前端依赖。

## 版式与可視化

- 面向长视频的知识阅读，而非营销落地页：浅蓝灰画布、深蓝灰正文、青绿色定位标识；不使用紫色或无意义动画。
- 首屏呈现视频标题、核心概括与实际内容统计；统计从 summary/segments 计算。
- 章节用路线导航和纵向时间轴呈现，时间来自引用段落的真实起点，标明“不是章节精确起止”；无时间戳则明示未知。
- 核心结论、详细章节、论据、作者建议、不确定性全部保留；不因为美化省略限制说明。
- 每条观点可展开连续原文引用，再跳转到对应全文段落。正文预渲染，脚本不可用仍可阅读。
- 全文搜索仅在当前页面过滤文本，零网络请求；链接回查清空筛选并展开原稿。
- B站完整链接的定位链接保留分P与原查询参数，只更新 t 秒数；非B站及短链不猜时间参数。
- 布局支持桌面与手机，普通按钮至少44px，键盘焦点可见；打印时展开原文，内容不截断。

## 事实与安全

- 必须先 validate_summary 再生成页面。段落ID映射成内部锚点，不将不可信ID拼入代码。
- 所有标题、正文、引文与URL属性转义；来源URL仅接受 HTTP(S)，拒绝 javascript/data/file 和带账号密码的URL。
- 不将转写文本拼到脚本；不使用 innerHTML 注入、不远程取库/字体/媒体、不埋追踪脚本。
- 用完整可读文本呈现风险，不用颜色单独表示信息等级；历史价格不得重新标成当前报价。
- 云端保留规则固定提示。网页不保存“媒体已删除”等易过期运行状态，实际清理状态只看 task.json。

## 升级与回归

`render-html` 给 v1 已完成任务补页，或在渲染器更新后重生成；原文/总结哈希保持不变。已有任务管理的旧页面自动备份，同名用户文件不覆盖。HTML 纳入 v2 产物清单，缺失或被改动会阻止清理。

运行 `python3 scripts/test_video_notes.py` 做脚本回归。页面视觉只用当前 HTML Skill 的 `scripts/shot.py` 生成双视口截图，读取报告和图片；修复后重跑，不另起浏览器自动化路径。
