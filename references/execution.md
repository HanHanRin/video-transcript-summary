# 执行与恢复

## 运行准备

命令均使用 `python3 本Skill绝对路径/scripts/video_notes.py`。输入和标题不拼 shell 字符串；源链接保存到 UTF-8 文件后用 `--source-file`。工具每次 fetch 会新建独立目录，重跑会产生后缀避免覆盖旧结果。

若缺少 PyAV，在本 Skill 独立目录运行 `python3 -m pip install --target 本Skill/.runtime/pythonlibs av`。这不购买 ASR 服务。若无安装授权、无法联网或无兼容版本，停下说明真实限制。

本机 `.runtime` 是环境依赖而非可移植源代码，迁移机器时重新检查，不把二进制依赖当成跨平台包。

## 妙记仍在处理中

1. 读取当前安装的 `lark-meeting/SKILL.md` 以及妙记读取场景；仅操作此任务已经返回的妙记，不搜索无关会议。
2. 优先运行本 Skill `recover --job 本任务`。它只从本任务后端返回提取已有标识，在任务目录执行结果读取，使用相对输出路径，成功后自动导入；不重新上传，不猜标识。正常 fetch 使用下游明确支持的系统临时目录暂存文字后归档，音视频始终在本任务目录。
3. 只在明确 not ready 时有界等待；时间估计来自 backend-result 的 wait_estimate，不编造进度百分比。权限、登录、额度错误立即停止。
4. 状态 ready 且全文本成功读回后，`ingest --job 本任务 --transcript 本任务内真实transcript.txt --method cloud_asr`；仅存在部分 transcript 不能进入完整总结。
5. 进程退出但已上传成功时，不重新上传；保留任务和后端返回，用已有妙记继续获取。

## 错误边界

- 412/429：平台访问或限流；遵循视频提取器的有限重试，未成功不能用网页简介冒充文字稿。
- missing dependency：在 Skill 独立依赖目录补齐，不改系统环境。
- permission/auth/scope：停下并报告当前操作未完成，不换第三方云 ASR 绕过。
- 无语音/空稿：不能生成虚假的内容总结，保留失败状态。
- 多P：一条 URL 对应一个具体页面，保留 p 参数；用户明确要全部分P时先确定列表，每P单独完成、分别标记。不要声称默认就处理了全合集。
- 下载器若使用任务外降级目录：拒绝自动删除它。记录准确路径和问题，不递归清理公共缓存。
- 清理中途失败：文本已安全保存，任务仍未 complete；修复具体问题后重试 cleanup，勿重新下载转写。

## 输出状态

- `needs_summary`：已归档转写，等待助手语义总结。
- `ready`：总结、HTML与证据文件校验通过，尚未清理；不等于网页已经视觉预览。
- `complete`：本任务媒体清理完成，文稿和HTML哈希回读通过。旧版任务先用 `render-html --job 任务目录` 补页，不重复下载或转写。
- `cloud_media` 是单独维度，不因本地 complete 而改成已删除。

文件完整性和引文校验由脚本负责，语义质量由助手复核；两者不可互相替代。
